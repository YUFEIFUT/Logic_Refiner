# 需求：逻辑精炼流程修正——回归证伪驱动的迭代精炼

## 背景

### 项目的初衷

LogicRefiner 的核心目标是**自动化人类的认知精炼过程**。以"努力就一定能成功"为例，人类的自然认知过程是：

1. 观察到反例：有些人非常努力却没有成功
2. 修正表述："努力不一定能成功"
3. 进一步思考：努力和成功是什么关系？不是充分必要条件
4. 继续观察：有些人不太努力，靠运气+做对了事也成功了
5. 解构概念：什么是"成功"？
6. 持续迭代：直到当前表述在已知范围内找不到轻易的反例
7. 最终标准：表述简洁（奥卡姆剃刀）、难以证伪、准确描述因果关系

这个过程的理论基础来自毛泽东《实践论》的核心循环：

```
实践 → 认识 → 再实践 → 再认识 → ...（螺旋上升）
```

### 当前系统的问题

当前系统的问题**不是简单的"主题漂移"**，而是更根本的：

1. **缺少证伪检验环节**：Synthesizer 修正后，没有检验新表述是否比旧表述更难证伪
2. **Crystallization 的目标错误**：追求"形而上""震撼"，而非"难以证伪、简洁、准确"
3. **迭代方向不明确**：系统在做"变换"（产出更新的东西），而非"精炼"（朝着更难证伪的方向迭代）

## 设计原则

| 原则 | 含义 |
|------|------|
| **证伪驱动** | 每一轮迭代的目标是产出比上一轮更难找到反例的表述 |
| **奥卡姆剃刀** | 最终表述应尽可能简洁——真理往往是简单的 |
| **实事求是** | 挖掘事物本质，不追求形式上的"震撼"或"形而上" |
| **系统性视角** | 将命题放在更大的系统中理解——考虑反馈循环、涌现属性、跨尺度关联 |
| **主题锚定** | 始终围绕用户最初输入的逻辑命题展开，不脱离主题 |

### 1.2 Synthesizer prompt 加入证伪约束

**目标**：确保 Synthesizer 产出的新表述比旧表述更难证伪。

**修改位置**：`server.ts` 第 149-156 行

**修改内容**：在 `synthesizerPrompt` 中加入以下约束：

```
【核心约束】：
你产出的新表述必须满足：
1. 比当前逻辑更难找到反例——如果你无法让新表述更难证伪，就明确说明当前表述已经是最佳状态
2. 尽可能简洁（奥卡姆剃刀原则）——不要引入不必要的变量或条件
3. 准确描述变量之间的因果关系，不多不少
4. 与原始命题相关，不脱离主题
```

**验收标准**：
- [x] Synthesizer prompt 包含"比当前逻辑更难找到反例"的约束
- [x] Synthesizer prompt 包含"奥卡姆剃刀"的约束
- [x] 当无法进一步精炼时，Synthesizer 能明确说明

### 1.4 Crystallization prompt 重新设计

**目标**：将 Crystallization 从"产出形而上结论"改为"产出经过证伪检验的、简洁的、难以反驳的逻辑表述"。

**修改位置**：`server.ts` 第 179-191 行

**修改内容**：

**删除所有以下表述**：
- "最震撼"
- "形而上逻辑结论"
- "真理律则"
- "充满张力与克制的美感"
- "形而上、极具深度"
- "进化真理"

**替换为以下核心要求**：

```
请基于以下所有分析过程，产出一个经过证伪检验的、简洁的、难以反驳的逻辑表述。

分析过程：
- 初始架构：${architectOutput}
- 最终演化逻辑：${currentLogic}
- 边界分析：${boundaryOutput}
- 原始命题： "${input}"

【核心标准 - 极其重要】：
1. 难以证伪：在目前已知的认知范围内，找不到轻易推翻它的反例
2. 奥卡姆剃刀：表述尽可能简洁，不引入不必要的变量或条件——真理往往是简单的
3. 准确描述因果关系：不多不少，恰好说清楚变量之间的本质关系
4. 与原始命题相关：必须是对原始命题的精炼，而非脱离主题的新创造
5. 具备系统性视角：揭示命题在更大系统中的位置、边界和相互作用

【禁止事项】：
- 绝对不要产出"形而上""震撼""充满张力"等形式化表述
- 绝对不要将抽象概念强行塞进数学或物理公式

【期望结果】：
一个简洁、准确、难以反驳的逻辑表述，例如：
"努力是成功的必要非充分条件，其有效性受方向选择、环境结构和随机因素共同调节。"

仅输出这句精炼结论，绝不要带有任何前言、引言、多余说明。
```

**验收标准**：
- [x] Crystallization prompt 不包含"形而上""震撼""张力"等表述
- [x] Crystallization prompt 包含"难以证伪""奥卡姆剃刀"等关键词
- [x] Crystallization prompt 包含原始输入 `input`
- [x] Crystallization prompt 包含系统性视角要求
- [x] 产出的结论与原始命题相关
- [x] 产出的结论简洁、难以反驳

## 整体验收标准

### 功能验收

以"努力就一定能成功"为测试输入：

- [ ] 最终结论与"努力""成功"相关，不脱离主题
- [ ] 最终结论简洁，不冗长（符合奥卡姆剃刀）
- [ ] 最终结论在已知范围内难以找到轻易的反例
- [ ] 最终结论准确描述了变量之间的因果关系（如：努力是必要非充分条件，受其他因素调节）
