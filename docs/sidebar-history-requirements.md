# LogicRefiner 侧边栏历史记录重构 - 需求文档

## 概述

将现有的折叠面板式历史记录重构为主流 Chatbot 风格的侧边栏设计，提升用户体验和界面专业度。

---

## 需求 1：基础侧边栏框架 ✅

**目标**：实现可折叠的侧边栏容器，主内容区可自适应宽度。

### 子任务

- **1.1** ✅ 创建侧边栏组件 `Sidebar`，固定在页面左侧，初始状态为收起
- **1.2** ✅ 侧边栏宽度设置：桌面端为屏幕宽度的 1/5（20%），收起时宽度为 0
- **1.3** ✅ 主内容区根据侧边栏状态动态调整宽度（`margin-left` 或 `width` 计算）
- **1.4** ✅ 添加侧边栏切换按钮（汉堡菜单图标），位于页面左上角
- **1.5** ✅ 点击切换按钮时，侧边栏滑入/滑出，带 200ms 过渡动画
- **1.6** ✅ 侧边栏收起时，主内容区占满全宽
- **1.7** ✅ 侧边栏展开时，主内容区向右挤压

### 验收标准

- [x] 侧边栏可正常展开/收起
- [x] 主内容区宽度随侧边栏状态平滑变化
- [x] 动画过渡自然，无闪烁

---

## 需求 2：侧边栏内容布局 ✅

**目标**：设计侧边栏内部结构，包含操作区和历史记录列表。

### 子任务

- **2.1** ✅ 侧边栏顶部放置"新建对话"按钮（+ 图标）
- **2.2** ✅ 侧边栏顶部放置收起按钮（<< 图标）
- **2.3** ✅ 历史记录列表区域占据侧边栏主体空间
- **2.4** ✅ 列表区域支持滚动（内容超出时）
- **2.5** ✅ 侧边栏背景色设置为深色（与主内容区区分）

### 验收标准

- [x] 侧边栏布局清晰，功能分区明确
- [x] 新建对话按钮可见且可点击
- [x] 收起按钮可见且可点击

---

## 需求 3：历史记录列表展示 ✅

**目标**：在侧边栏中展示历史精炼记录，支持点击查看详情。

### 子任务

- **3.1** ✅ 从 API 获取历史记录列表
- **3.2** ✅ 每条记录显示：输入内容（截断）、日期、演化轮数
- **3.3** ✅ 记录项支持点击，加载该记录的详情到主内容区
- **3.4** ✅ 当前选中的记录有高亮样式（左侧指示条或背景色变化）
- **3.5** ✅ 记录列表按时间倒序排列
- **3.6** ✅ 空状态显示提示文字（如"暂无历史记录"）

### 验收标准

- [x] 历史记录正确加载并显示
- [x] 点击记录可查看详情
- [x] 当前选中有视觉反馈
- [x] 历史记录多时可滚动查看

### 子任务

- **4.2** ✅ 记录项悬停时显示删除按钮（垃圾桶图标）

- **4.5** ✅ 记录项文字超长时显示省略号
- **4.6** ✅ 删除成功后显示 Toast 提示
- **4.7** ✅ 删除当前正在显示的记录时，清空主页面内容

### 验收标准

- [x] 悬停效果正常
- [x] 删除功能正常，有确认机制
- [x] 文字截断显示正确

## 需求 6：响应式适配

**目标**：在不同屏幕尺寸下提供良好的用户体验。

### 子任务

- **6.1** 桌面端（>768px）：侧边栏宽度为屏幕宽度的 1/5，主内容区挤压
- **6.2** 移动端（<=768px）：侧边栏宽度为屏幕宽度的 95%，覆盖式滑出，背景变暗
- **6.3** 移动端点击侧边栏外部区域时，自动收起侧边栏
- **6.4** 移动端侧边栏覆盖在主内容区上方，不挤压主内容

### 验收标准

- [ ] 桌面端布局正常
- [ ] 移动端侧边栏覆盖显示
- [ ] 移动端点击外部可关闭

## 技术注意事项

- 侧边栏组件应独立于 `App.tsx`，放在 `src/components/Sidebar.tsx`
- 历史记录状态管理可考虑使用 Context 或保持在 App 层
- 动画使用现有依赖 `motion/react`（Framer Motion）
- 响应式断点使用 Tailwind CSS 的 `md:` 前缀
