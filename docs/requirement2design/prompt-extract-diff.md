- **唯一的内容性新增**：商定的反公式约束（T1–T5），集中在每个节点的 system 末尾、prompt 的【核心约束】/【格式约束】段，以及全局提示。

## 4. 一处必须如实说明的迁移副产物（无害）

原 `server/index.ts` 中，所有内联模板字符串为对齐代码排版，每行开头都带有若干**代码缩进空格**（例如 `    如果输入是一个问题……` 前的 4 个空格）。抽取到 `server/prompts.ts` 后，这些**行首空白被清理为顶格**。

- 性质：纯代码格式化副产物，**不属于用户商定的改动**，也不影响提示语义（这些空格本就是代码缩进，不在语义关键处）。
- 影响：对模型实际输入而言，相当于去掉了每行开头的无意义空白，提示的「可读文本」内容不变。
- 若你希望 `prompts.ts` 与原始运行时字符串**字节级完全一致**（连行首空格都还原），我可以补一个 diff 核对并加回，但通常无必要。
